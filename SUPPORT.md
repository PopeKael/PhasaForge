# Support

For a published build, report issues in the PhasaForge GitHub issue tracker when it is enabled. During private testing, use the contact channel provided with the test build.

Include:

- PhasaForge version and Windows version.
- Selected translation provider and Thai voice/backend.
- Steps to reproduce and expected versus observed behavior.
- A short error message or screenshot when useful.

Do not attach API keys, passwords, Credential Manager exports, private text, recordings, model caches, or unredacted diagnostic logs.

## Garage Alchemy community and optional support ☕

For issues during private testing, use [Wazza Garage issues](https://github.com/PopeKael/wazza-garage/issues) with `PhasaForge:` at the start of the title.

PhasaForge is an independent project shared through [Garage Alchemy](https://garage.dia.net.au/). No payment or subscription is required to use it. If you'd like to support Wazza's work, contributions are optional: [Buy Me a Coffee](https://buymeacoffee.com/warrengerdes) · [Join the Tribe on Patreon](https://www.patreon.com/c/chanyawazza). These links support the maintainer, not upstream dependency authors.
