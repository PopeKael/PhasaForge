Thai text and translation

Azure F0 is the normal translator for this app. The saved key is checked automatically. Leave this section as it is unless you want to change translation providers.

Checking this PC for Ollama and installed models…

Select a model that the existing Ollama service lists, then click Save Settings to ask that service to load it. PhasaForge does not start or restart Ollama. The model uses system memory or GPU memory while loaded.

Checking Ollama's loaded models…

Azure F0 translates automatically using the free monthly quota and a 1.9M character safety cap. Its key stays in Windows Credential Manager. Ollama can be selected as an optional local fallback when Azure is unavailable.
