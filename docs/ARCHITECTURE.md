# Architecture

- **Rust/Tauri host:** Owns the hidden/revealed window, tray and keyboard hook. `tauri-plugin-single-instance` is registered first; its activation callback reveals and focuses the existing main window.
- **Hotkey:** The low-level hook only tracks configured modifier and trigger. On activation an action worker reads the selection first, then explicitly shows/focuses the window and emits the capture result. The frontend places it beside the selection/cursor, clamps it to the corresponding monitor work area, and displays captured text.
- **Thai analysis:** `kham-core` provides offline sentence segmentation and newmm word segmentation. The vocabulary overlay is loaded from SQLite at startup. The English/romanization database lookup is separate from segmentation and separate from translation.
- **SQLite:** `assets/learner.sqlite` is a generated subset of ThaiReader v42 (word entries, senses, examples, source rows), plus a clearly distinguished project-provided sample. On first launch the app copies it to the platform app-data folder as `phasaforge.sqlite` and creates a separate `corrections` table. User data therefore survives installer upgrades. Regenerate the bundled seed with `python scripts/build_learner_db.py` after changing the attributed TSV snapshot.
- **Translation:** Speech recognition, text translation, and speech synthesis are independent paths. Azure Translator reads the key and region saved in Windows Credential Manager for the current Windows account; it adds the region header only when a region is supplied, so a global resource may leave it blank. PhasaForge never bundles a developer key or reads another Windows account's credentials. The selected provider is persisted and used for sentence and Practice translation: Azure, local Ollama (with the existing Azure fallback behavior), or offline examples. Ollama uses native Rust HTTP requests to the local `OLLAMA_HOST` (default `127.0.0.1:11434`). Startup discovery only reads Ollama's API and model manifests. It does not load a model, alter `OLLAMA_MODELS`, or restart the service; loading a model is an explicit Save action. `api/pull` downloads only a user-entered model after the user presses Download. No text is sent to Thai2English.
- **Selected-text history:** The ten newest distinct Thai source texts and their sentence cards (segmentation, readings, dictionary results and available translations) are retained in local WebView storage. Current-version history navigation renders saved cards without another analyzer or translation-provider call. Old analysis versions are refreshed with the local analyzer on first revisit; cached translations are preserved and no provider is called. Reselecting identical text reuses its record. Current Sentence navigation remains within the chosen text record.
- **Thai Character Inspector:** The large selected word in the Words panel stays a single Thai text node. Transparent hit areas use browser range geometry plus font metrics for combining marks. The offline character table supplies names; bundled dictionary syllable readings and tone labels are combined with verified spelling boundaries for supported examples and simple one-syllable words. Tone explanations use consonant class, vowel length, coda type, and written tone marks following the [Chulalongkorn University Thai writing and romanisation reference](https://www.arts.chula.ac.th/~ling/contents/File/%E0%B8%AD%E0%B8%B1%E0%B8%81%E0%B8%A9%E0%B8%A3%E0%B8%A7%E0%B8%B4%E0%B8%98%E0%B8%B5%E0%B9%84%E0%B8%97%E0%B8%A2.pdf). Multi-syllable spellings with unresolved boundaries retain the character-only fallback rather than inventing a syllable alignment. Sentence and Practice text are unchanged.
- **Windows sign-in startup:** Tauri's autostart plugin manages an optional per-user registration. It defaults off, reflects the actual Windows setting, and only changes registration when the saved selection differs.
- **Speech:** Local Meta MMS-TTS Thai is the default for new configurations; Windows WinRT and Thai Web Speech voices remain selectable alternatives. When MMS is selected and cached, startup loads it with local-only model access, then silently runs one inference on the persistent CPU worker. The worker remains resident through window hiding and stops on app exit. Explicit Download + test and Play actions retain model installation behavior. Model-load, warm-up and click-to-WebView-`playing` timings are logged. Microphone practice records and replays audio, releases microphone tracks on stop, and stores the last ten takes with the recognized text, English translation and timestamp in local app data. Selecting history restores those saved values and original audio without rerunning either model; Clear History deletes metadata and audio. Optional Thai ASR is prepared on demand in an isolated Python environment under app data. After Stop, Web Audio decodes and resamples the recording, Rust stages a temporary 16 kHz WAV, and a short-lived sherpa-onnx CPU process transcribes it with the int8 Thai Zipformer model. Whisper.cpp was the initial proposal; sherpa-onnx was the implemented replacement and remains the selected backend. The temporary WAV is removed after transcription; no audio is uploaded. This offline model does not provide interim words during recording. No pronunciation or tone score is produced.
- **Updates:** The Tauri updater plugin, public verification key and HTTPS feed configuration are present, and build signing is protected outside Git. Version 1.0.0 does not call the updater API or check for updates automatically. The signed installation and feed cycle still needs an explicit 1.0.0 → 1.0.1 deployment test.
- **Frontend:** Vite, TypeScript and plain DOM/CSS. The Settings view is an internal scrollable page. User-facing messages expose unavailable providers and missing data instead of silently substituting content.
- **Window placement:** Existing physical-pixel monitor/work-area calculation is retained. The custom title bar remains draggable; fixed dimensions match the 640×480 concept.
- **Assets/data:** UI artwork is the supplied project artwork. The learner data license is separate from MIT app source and is reproduced in `reference-data/thaireader-v42/THAI-LEXICON-LICENSE.md`. No media-library files are included.
